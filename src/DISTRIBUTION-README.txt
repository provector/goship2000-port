GoShip 2000
Place your legitimately obtained game files under original/ or choose their location in SETUP. When preparation needs originals, the game also checks local Steam libraries for app 2766090. Run gs2000 to play. On Linux run ./setup or use the supplied launcher. On Windows use setup.exe. Keep the platform SDL2 runtime, support.g2pak and launcher resources with their executables.

The game and SETUP read config.g2pak from Documents/GoShip 2000 on Windows or ~/.goship2000 on Linux. If that folder is unavailable, the installation directory is used. An explicit -app-dir selects a self-contained installation. For a separate personal store set GOSHIP2000_DATA_DIR to an absolute directory. The configured saves directory contains the six player packs under pilots/, missions/, replays/ and SUMMARY.TXT when generated. Reports, import archives, temporary conversion work and screenshots use sibling directories beside the configured saves directory. Back up config.g2pak with the complete saves tree and any import archives. Prepared assets stay under the configured assets directory. Preparation uses the embedded converter without requiring a compiler.

Back up your application configuration and saves together. On first upgrade, close other game and SETUP instances. On first use the game or SETUP verifies and moves installation-local data to an empty personal store. An established destination takes priority and leaves conflicting older installations intact. The GPS catalogue can be edited with the game and SETUP closed: back up config.g2pak, edit gps_codes.json, replace that one entry using ZIP STORE (no compression), and preserve every other entry and its name. Keep codes as five-character strings. Consult GoShip_2000_Copy_Protection_Codes.txt alongside your original game reference.

Third-party notices are in Licenses.txt. support.g2pak is an ordinary ZIP containing helper source, build instructions and notices. Extract the ZIP and see audio-preparation-source/src/internal/audioopl/source/BUILD.md to rebuild the helper. Provide your own original game assets.

Share a native mission by copying its .g2m into saves/missions, or a published portable .g2r into saves/replays. Reopen the library. Matching game resources are required. Old compressed recordings migrate on normal startup when publication and companion identities can be verified. Unfinished recordings stay private. On a new career store an original roster takes precedence over the bundled default roster.

Linux ARM64 (Raspberry Pi 5): Extract the complete package together, including lib/. Start ./gs2000 or ./setup in the extracted directory. The game uses the bundled raylib 6.0 GLES renderer. Use a 64-bit desktop with X11 or XWayland, libX11, glibc 2.38 or newer and a working Mesa EGL/OpenGL ES 2 driver. No raylib installation or shell graphics overrides are required.

F12 writes PNG images to screenshots/ beside the configured saves directory. The directory is created on the first capture. Existing development screenshots stay in their original location. The game reports the actual target path if writing fails.
